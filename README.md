# Tic-Tac-Toe Game

## Project Overview
This is a simple **Tic-Tac-Toe** game built using **HTML, CSS, and JavaScript**. The game allows two players to take turns marking spaces in a 3×3 grid. The first player to align three marks (horizontally, vertically, or diagonally) wins!

## Features
- Interactive game board.
- Two-player functionality.
- Win, draw, and reset conditions.
- Simple and responsive UI.

## Technologies Used
- **HTML**: Structure of the game board.
- **CSS**: Styling for the board and game elements.
- **JavaScript**: Game logic and interactivity.

## Setup and Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/Tic-Tac-Toe-Game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Tic-Tac-Toe-Game
   ```
3. Open `index.html` in a web browser to start playing.

## How to Play
- The game starts with Player X.
- Click on an empty cell to place your mark.
- Players take turns until one wins or the game ends in a draw.
- Click the **Reset** button to start a new game.
